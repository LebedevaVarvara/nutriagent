# NutriAgent - консольный помощник по питанию

## Технологический стек
- Язык: Python 3.9+ (используется только стандартная библиотека, внешние зависимости отсутствуют).
- Среда выполнения: CPython.
- Менеджер зависимостей: pip (venv).
- Линтер и форматтер: Ruff.
- Отладчик: Встроенный отладчик VS Code.
- Хранение данных: В оперативной памяти (сбрасывается при выходе).

## Подготовка окружения и запуск
1. Клонируйте репозиторий: git clone <ссылка>
2. Создайте виртуальное окружение: python3 -m venv .venv
3. Активируйте его: source .venv/bin/activate
4. Установите линтер: pip install ruff
5. Запустите приложение: PYTHONPATH=src python -m agent

## Команды приложения
- profile <пол> <возраст> <вес> <рост> <активность> - расчет нормы КБЖУ и воды. Пример: profile ж 25 60 165 средняя
- eat <продукт> <граммы> - добавить прием пищи. Пример: eat овсянка 200
- water <мл> - добавить воду. Пример: water 250
- status - показать прогресс за день
- help - справка
- exit - штатное завершение

## Хранение данных
Все данные хранятся в оперативной памяти (объект AppState в storage.py). После завершения программы данные сбрасываются.

## Проверка качества кода
Для форматирования: ruff format .
Для проверки: ruff check .

## Примеры диалога

Пример 1 (Успешный расчет и дневник):
nutri> profile ж 25 60 165 средняя
Профиль сохранен!
Ваша норма: 1935 ккал, Б: 145.1г, Ж: 64.5г, У: 193.5г. Вода: 1800 мл.

nutri> eat овсянка 200
Записано: овсянка (200.0г) = 700 ккал. Съедено за день: 700 ккал. Осталось: 1235 ккал.

nutri> exit
До встречи!

Пример 2 (Обработка ошибок ввода):
nutri> water 300
Ошибка: Сначала настройте профиль командой 'profile'.

nutri> profile неизвестно 25 60 165 средняя
Ошибка: Недопустимый пол: 'неизвестно'. Допустимые: м, ж.

nutri> eat банан -100
Ошибка: Количество грамм должно быть положительным конечным числом.

nutri> abracadabra
Ошибка: неизвестная команда 'abracadabra'. Введите 'help'.
