
# NutriAgent — консольный помощник по питанию

## Технологический стек
- **Язык:** Python 3.9+ (используется только стандартная библиотека).
- **Среда выполнения:** CPython.
- **Менеджер зависимостей:** pip (venv).
- **Линтер и форматтер:** Ruff.
- **Тестирование:** unittest + coverage.
- **Отладчик:** Встроенный отладчик VS Code.
- **Хранение данных:** Локальный файл `state.json` (JSON).

## Подготовка окружения и запуск
1. Клонируйте репозиторий: `git clone <ссылка>`
2. Создайте виртуальное окружение: `python3 -m venv .venv`
3. Активируйте его: `source .venv/bin/activate`
4. Установите зависимости: `pip install ruff coverage`
5. Запустите приложение: `PYTHONPATH=src python -m agent`

## Команды приложения
- `profile <пол> <возраст> <вес> <рост> <активность>` — расчет нормы. Пример: `profile ж 25 60 165 средняя`
- `eat <продукт> <граммы>` — добавить еду. Пример: `eat овсянка 200`
- `water <мл>` — добавить воду. Пример: `water 250`
- `status` — показать прогресс
- `help` — справка
- `exit` — выход

## Хранение данных
Состояние (профиль, съеденные калории, выпитая вода) сохраняется в файл `state.json` в корне проекта. 
Сохранение происходит **при выходе из программы** (команда `exit` или Ctrl+C). 
При запуске программа автоматически загружает данные из этого файла. Если файла нет (первый запуск), начинается с пустого состояния.

## Тестирование и проверка качества кода
Запуск тестов: `PYTHONPATH=src python -m unittest discover -s tests -v`
Замер покрытия: `PYTHONPATH=src coverage run -m unittest discover -s tests` и `coverage report -m`
Форматирование: `ruff format .`
Линтер: `ruff check .`
